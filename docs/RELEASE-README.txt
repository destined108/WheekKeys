WheekKeys — Guinea Pig Desktop Pet / 豚鼠桌宠

Windows 10/11 x64. Unzip this folder and run WheekKeys.exe.
No Python installation needed. This preview executable is unsigned.

Type normally in another app. Hay grows and your cavy comes to eat.
Right-click the pet or its tray icon for settings, models, colors and quitting.
Drag the pet with the left mouse button. The tray icon may be under the
hidden-icons arrow. Language can follow your system or be selected manually.

The app counts new key presses, without converting them to text, saving them
or sending keyboard data anywhere. Hold a key: it counts once.

Custom colors: choose Import colors and select the palette JSON.
Custom models: unzip the model ZIP, choose Import model, then select the
folder containing model.json. Do not place files next to this executable.

解压后运行 WheekKeys.exe，无需安装 Python。适用于 Windows 10/11 的 64 位系统。
本次为早期试玩版，程序尚未签名。

在其他应用中正常打字即可长草，豚鼠会跑来吃。
右键点击宠物或托盘图标，可以设置参数、换模型、导入花色或退出。
左键拖动宠物；托盘图标可能藏在通知区域的隐藏图标中。
可在语言菜单中选择简体中文、繁體中文、English，或跟随系统。

程序只统计新按下的次数，不转换、保存或上传输入内容。长按只算一次。
导入花色时选择 JSON 文件；导入模型时先解压，再选择包含 model.json 的文件夹。
不需要把自定义素材放在 exe 旁边。
