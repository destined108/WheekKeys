## WheekKeys v0.1.0 — Windows preview

Type a little. Grow hay. Feed your cavy.

Download **WheekKeys-Windows-x64.zip**, unzip it, and run **WheekKeys.exe** on Windows 10/11 (x64). No Python installation is needed. The standalone exe is also available. `SHA256SUMS.txt` contains download checksums. This early preview is unsigned.

- Typing grows hay; your guinea pig scurries over, chews and returns to rest.
- Tray and pet right-click menus: feed, hide/show, change model, import colors, settings and quit.
- English, Simplified Chinese and Traditional Chinese, with automatic system-language detection and manual switching.
- Persistent settings: 1–1000 key presses per meal, movement speed, size, always-on-top and pause.
- Custom model packs and palettes, plus an agent skill to make your own cavy.
- Fixed chewing shimmer, UTF-8 palette loading, invalid-model isolation, hex color case differences, animation skipping after stalls and interrupted slow demo loops.

The app counts new key presses without converting them to text, saving events or sending keyboard data anywhere. Use normal launch for real typing; `--demo` plays an automatic preview. Windows desktop behavior beyond automated checks may still need testing on your machine.

## 中文说明

**敲键盘长牧草，豚鼠跑来吃。**

下载 **WheekKeys-Windows-x64.zip**，解压后运行 **WheekKeys.exe**，适用于 Windows 10/11 的 64 位系统，无需安装 Python。也可直接下载单独的 exe。`SHA256SUMS.txt` 提供文件校验值。本次为早期试玩版，程序尚未签名。

- 打字长草，豚鼠跑来吃完，再回去趴下。
- 支持托盘和宠物右键菜单，可喂草、显示／隐藏、更换模型、导入花色、打开设置和退出。
- 支持简体、繁体和英文，可跟随系统，也可手动选择。
- 可保存吃草所需按键次数（1～1000）、移动速度、显示大小、置顶和暂停设置。
- 支持自定义模型、花色，以及交给 agent 制作宠物的 skill。
- 修复嚼草画面跳动、花色编码、损坏模型、颜色大小写、卡顿后跳过动画，以及慢速演示被截断的问题。

程序只统计新按下的次数，不转换、保存或上传输入内容。正常启动即可随打字互动；`--demo` 为自动演示。自动测试之外的 Windows 桌面效果仍可能需要在你的电脑上验证。
