## WheekKeys v0.1.1 — Mochi joins the desktop

**Mochi** is now bundled alongside **Potato**. Right-click the pet or tray icon → **Pet model → Mochi**. No model download, import, or Python installation is needed. Your selection is remembered after restart; your existing model preference is preserved on upgrade.

- Complete cream-and-caramel artwork: awake, chewing, sleeping, and four walking frames.
- Built-in model names follow the interface language: Mochi / 奶糖.
- Both English and Chinese READMEs now show Mochi's ten-second GIF.
- Model resources are included inside the executable; custom model import remains available.

Download **WheekKeys-Windows-x64.zip**, unzip and run **WheekKeys.exe** (Windows 10/11 x64). The standalone exe and `SHA256SUMS.txt` are also available. This preview executable is unsigned.
