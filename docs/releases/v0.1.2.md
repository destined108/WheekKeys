## WheekKeys v0.1.2 — Windows build fix

Includes both built-in pets, **Potato** and **Mochi**, with the same features and artwork as v0.1.1.

Fixes a Windows CI test that compared a canonical model path with an unresolved temporary directory. Windows short (8.3) directory aliases can refer to the same folder but fail a purely lexical containment check. The test now resolves the temporary directory before comparing, while retaining its resource-loading and rendering checks. No application behavior changed.

Download **WheekKeys-Windows-x64.zip**, unzip and run **WheekKeys.exe**. Requires Windows 10/11 x64; Python is not required. The preview executable is unsigned. Checksums are provided in `SHA256SUMS.txt`.

## 中文说明

包含内置的「土豆」和「奶糖」，功能与素材和 v0.1.1 相同。

修复 Windows 构建测试中的路径误判：临时目录可能使用短路径别名，而模型加载器返回规范化后的完整路径，两者实际指向同一目录，直接比较却会失败。现在先统一规范化路径，再检查模型是否位于打包目录内，仍保留资源加载和渲染验证。本次未更改程序行为。

下载 **WheekKeys-Windows-x64.zip**，解压后运行 **WheekKeys.exe**。适用于 Windows 10/11 的 64 位系统，无需安装 Python。试玩版尚未签名，`SHA256SUMS.txt` 提供校验值。
