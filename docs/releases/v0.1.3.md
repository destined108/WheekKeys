## WheekKeys v0.1.3 — Manage imported pets

Open **Settings → Manage pet models** to see built-in and imported pets and remove models you no longer need.

- Select an imported model and click **Delete selected model…**. Confirmation is required; deletion takes effect immediately.
- Only the installed copy is removed. Original source files are kept.
- Deleting the active model switches to Potato and saves that selection first. If saving fails, deletion is cancelled.
- Built-in Potato and Mochi are protected from deletion.
- Model management, confirmation and errors support English, Simplified Chinese and Traditional Chinese.

Validated with 46 passing tests; the native Windows keyboard test was not run on the Linux development machine and remains part of Windows CI.

Download **WheekKeys-Windows-x64.zip**, unzip and run **WheekKeys.exe**. Requires Windows 10/11 x64, with no Python installation needed. This preview executable is unsigned. `SHA256SUMS.txt` provides download checksums.

## 中文说明

新增 **设置 → 管理宠物模型**，可查看内置和已导入的宠物，删除不再需要的模型。

- 选中导入的模型，点击“删除所选模型…”，确认后立即生效，无需再点击保存。
- 只删除已安装的副本，原始素材文件保留。
- 删除当前模型时，先切回土豆并保存选择；保存失败则取消删除。
- 内置土豆和奶糖不能删除。
- 管理界面、确认和错误提示支持简体、繁体和英文。

本地 46 项测试通过；Linux 开发环境未运行 Windows 原生键盘测试，该项会在 Windows CI 中执行。

下载 **WheekKeys-Windows-x64.zip**，解压后运行 **WheekKeys.exe**。适用于 Windows 10/11 的 64 位系统，无需安装 Python。试玩版尚未签名，`SHA256SUMS.txt` 提供校验值。
