# Mochi / 奶糖

A fictional cream-and-caramel guinea pig, bundled with WheekKeys v0.1.1 and later.
Choose **Pet model → Mochi** without importing. The standalone pack also supports import tests.
Full custom artwork: four poses and a four-frame grounded walking cycle.
Created with AI assistance using WheekKeys' bundled artwork as a style/layout reference.
No personal photos are included. Project-provided artwork is distributed under MIT; see LICENSE.

## Import

1. Unzip `mochi-model.zip`.
2. Right-click the pet or tray icon → **Import model…**.
3. Select the extracted `mochi` folder containing `model.json` (not the ZIP).
4. The active pet should become cream-white and caramel. Look for **Mochi / 奶糖** under **Pet model**.
5. Type or feed manually, then restart the app to check that your selection is remembered.

The palette uses the default five reference values to preserve the newly painted artwork.
Its visible coat colors come from the PNGs, not the numeric palette values.
You do not need to copy anything next to the exe or rebuild the application.

v0.1.1 起已内置奶糖，可直接在“宠物模型 → 奶糖”中切换，无需导入。以下步骤适用于独立模型包或测试导入功能。

## 导入试用

1. 解压 `mochi-model.zip`。
2. 右键点击宠物或托盘图标，选择“导入模型…”（繁体界面为“匯入模型…”）。
3. 选中解压出来的 `mochi` 文件夹，里面应有 `model.json`。不要选择 ZIP 文件。
4. 宠物应变成奶油白和焦糖色；在“宠物模型”中可看到 **Mochi / 奶糖**。
5. 试试打字或手动喂草，再重启程序，确认模型选择被保留。
