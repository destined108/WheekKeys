# 换上你家豚鼠的花色

[English](README.md) · 简体中文 · [返回项目首页](../README.zh-CN.md)

花色文件只改变颜色，保留原来的外形和动作。如果你想自己画一只新角色，请看[模型制作指南](../models/README.zh-CN.md)。

可在宠物右键或托盘菜单的 **语言** 中选择简体中文、繁體中文、English，或跟随系统。下文同时列出简体中文和英文菜单名称，方便对照。

## 1. 复制花色模板

把 [template.json](template.json) 复制一份，命名为 `my-cavy.json`。保留字段名称，将颜色改成 `#RRGGBB` 格式的十六进制色值：

| 字段 | 用途 |
| --- | --- |
| `name` | 花色名称，不影响动画 |
| `fur` | 毛发的主要颜色 |
| `patch` | 深色斑块和耳朵外侧 |
| `cream` | 脸部、脚等部位的浅色毛发 |
| `ear` | 耳朵内侧、鼻子、爪子等粉色部位 |
| `eye` | 眼睛、嘴等深色细节 |

程序会根据原图的颜色识别换色区域，并保留明暗层次。上表是大致对应的部位，并不是每个部位都有独立图层。使用默认配色时，图片会保持原样。

## 2. 给宠物换上新花色

右键点击宠物或 Windows 托盘图标，选择 **导入花色…（Import colors…）**，再选中你的 JSON 文件。程序会把它复制到用户目录中，下次启动也会保留。切换模型时会恢复新模型自带的花色；如果想继续使用自己的配色，重新导入即可。

也可以在项目根目录用命令预览：

```sh
python -m wheekkeys --demo --skin skins/my-cavy.json
```

使用下载的 Windows 版时，可以指定本次运行使用的花色：

```powershell
.\WheekKeys.exe --skin "C:\path\my-cavy.json"
```

不需要重新打包程序。`--demo` 会自动播放动画；想在 Windows 上试试实际打字效果，去掉这个参数即可。从源码运行时，请使用已配置好依赖的虚拟环境中的 Python。

## 3. 分享你的作品

欢迎在 Issue 中分享截图或 GIF，也可以提交 PR，附上花色 JSON、花色名称和预览图。请只分享你有权公开使用的素材，文件中不要包含个人隐私信息。

想改变体型，或自己画跑步、吃草的动作？接着看[模型制作指南](../models/README.zh-CN.md)。
